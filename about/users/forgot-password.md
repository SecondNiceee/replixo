# Что делать, если забыл пароль

## Текущее состояние

На данный момент функция «Восстановление пароля» (сброс по email) **не реализована**.
Это связано с тем, что проект пока не использует почтовый сервис для отправки писем.

---

## Что можно сделать сейчас

### Если ты администратор / владелец сервера

1. Подключись к базе данных (через `psql` или любой SQL-клиент).
2. Найди аккаунт пользователя:
   ```sql
   SELECT id, email FROM "user" WHERE email = 'user@example.com';
   ```
3. В таблице `account` найди запись с `providerId = 'credential'` для этого `userId`.
4. Замени поле `password` на новый bcrypt-хэш нужного пароля.
   Пример генерации хэша (Node.js):
   ```js
   import bcrypt from 'bcryptjs'
   console.log(await bcrypt.hash('НовыйПароль123', 10))
   ```
5. Обнови запись в БД:
   ```sql
   UPDATE account SET password = '$2a$10$...' WHERE "userId" = '...' AND "providerId" = 'credential';
   ```
6. Сообщи пользователю временный пароль и попроси сменить его после входа.

---

### Если ты обычный пользователь

На данный момент единственный способ — обратиться к администратору сайта, который вручную сбросит пароль через БД (см. выше).

Страницы `/forgot-password` или «Восстановить пароль» пока не существует.

---

## Будущее: автоматический сброс пароля

Для полноценного восстановления пароля нужно:

1. **Подключить почтовый провайдер** (Resend, Nodemailer, Postmark и т. д.).
2. **Включить Better Auth email verification / password reset** — библиотека уже содержит этот функционал, достаточно передать `sendResetPassword` в конфиг:
   ```ts
   // lib/auth.ts
   emailAndPassword: {
     enabled: true,
     sendResetPassword: async ({ user, url }) => {
       await sendEmail({
         to: user.email,
         subject: 'Сброс пароля Riplexo',
         text: `Перейди по ссылке для сброса: ${url}`,
       })
     },
   },
   ```
3. **Добавить страницу `/forgot-password`** с формой ввода email.
4. **Добавить страницу `/reset-password`** — Better Auth сам обработает токен из URL и установит новый пароль.

---

## Смена username (не пароля)

Если пользователь просто хочет **сменить имя** — это уже доступно:
- Открыть страницу `/profile`
- Нажать на иконку карандаша рядом с именем
- Ввести новый username (только латинские буквы, цифры, _, 2–20 символов)
- Нажать Enter или кнопку подтверждения
